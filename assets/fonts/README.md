# Image label font

Noto Sans SC Regular 2.004, unmodified, distributed under the included SIL Open
Font License. Bundled for deterministic Chinese and Latin labels in headless PNG
rendering; no system fonts or runtime downloads are required.

Source: https://github.com/notofonts/noto-cjk/blob/Sans2.004/Sans/SubsetOTF/SC/NotoSansSC-Regular.otf

Original SHA-256: `faa6c9df652116dde789d351359f3d7e5d2285a2b2a1f04a2d7244df706d5ea9`

The `.zst` file is lossless compression, produced with `zstd -19` and decoded once
by the renderer. The font outlines and naming tables have not been modified.

The binary also embeds the copyright and full license through
`web/public/assets/NotoSansSC-OFL.txt`, served at `assets/NotoSansSC-OFL.txt`.
Keep that notice in sync when replacing the font.
