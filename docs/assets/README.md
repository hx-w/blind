# README artwork

`banner.png` is an original image generated with the built-in ImageGen tool for
Blind's README. The visual metaphor connects a terminal-created model to a
person inspecting that model on a phone through a shared link.

The direction was informed by the minimal editorial cartoon descriptions in
[yang0/handraw-style](https://github.com/yang0/handraw-style), particularly the
generic features of entry 018: simple silhouettes, restrained expressions,
limited color and visual humor. No reference artwork was copied into the banner.

## Generation prompt

```text
Use case: illustration-story.
Asset type: wide GitHub README banner for the open-source 3D review tool Blind. Create a finished original illustration, approximately 3:1 wide landscape, ideally 1800 x 600.
Concept: a terminal makes a 3D object; a shared link lets a person inspect it on a phone. Quiet nerd humor, not a corporate diagram.
Composition: one continuous editorial cartoon across warm off-white paper, generous margins and whitespace. At the upper left, the single word "Blind" in confident hand-lettered dark ink, large and legible. Along the lower two thirds, a small boxy terminal-headed robot at a laptop on the left has a deadpan >_ face. On its laptop screen is a blue low-poly wireframe rubber duck and tiny document sheets. A loose orange hand-drawn line with one recognizable chain-link symbol arcs across the middle to an oversized smartphone held by a relaxed human on the right. The same unmistakable blue wireframe duck is shown on the phone, tilted to a different angle, with a simple orbit arrow. The duck is the funny central visual motif; do not turn it into a real animal or human mascot. The robot looks matter-of-fact; the human leans in with curious concentration. Two small unlabelled file-sheet doodles can suggest notes alongside the model.
Style: minimal deadpan hand-drawn editorial cartoon. Slightly uneven charcoal pen outlines with visible hand pressure, flat muted blue and warm rust-orange accents, very subtle paper grain, simple compact silhouettes, restrained expressions, no glossy polish. Original character designs, no imitation of any named artist. Calm, clever, welcoming.
Text: only "Blind". No other text or pseudo-text; terminal >_ is allowed. No speech bubbles. Keep all important elements legible when displayed at 900 pixels wide.
Avoid: photorealism, 3D rendered characters, gradients, neon, heavy texture, grid panels, flowchart boxes, dense tiny interface details, watermarks, external logos, generic smiling corporate people. Full opaque light paper background.
```
